# 중계기, 실시간 시세를 고칠 때

사실관계는 `CONTEXT.md` "KRX 중계기" 절이 원본이다. 먼저 읽는다. 자주 틀린 것만 아래에 둔다.

- 시각: 1분봉 시각은 봉 종료 기준이다. KRX 공식 시가 = 09:01 봉의 시가, 종가 = 15:31 봉의 종가. 15:32~15:40 은 거래가 없고, 15:40 부터는 NXT 애프터마켓이다(2026-10-15, 10-18 수정 이력).
- 종목 일봉(1d)은 KRX, NXT 통합(08:00~20:00)이라 공식값이 아니다. 코스피 지수는 KRX 만이라 그대로 써도 된다.
- 토스 토큰은 클라이언트당 1개만 유효하다. 클라우드 세션에서 토스 API 토큰을 새로 발급하지 않는다(중계기 토큰이 무효가 된다). 이 세션의 출구 IP 는 미국 대역이라 직접 호출도 안 된다. 확인은 중계기를 거친다.
- `relay/` 를 머지해도 VM 에는 반영되지 않는다. 사용자가 VM 에서 `cd ~/jisikin-jogan && git pull && sudo bash relay/install.sh` 를 돌린다. 이 명령과 정상일 때 나와야 하는 응답을 PR 설명에 같이 적는다.
- 저장소는 Public 이다. 키, 토큰, 의견 원문을 코드, 로그, 커밋에 넣지 않는다.
- 누가 무엇을 키 없이 쓸 수 있는지(`PUBLIC_VIEW`, 의견 쓰기, 키 종류)를 바꾸는 수정은 구현 전에 사용자에게 묻는다. 지금 결정은 시세, 의견 모두 키 없이, 키는 루틴 키 하나다(`DIRECTION.md` 결정 기록 2026-10-19, 11-10). 보안 지적이 근거여도 닫는 쪽으로 먼저 고치지 않는다 — 2026-11-10 PR #58 이 의견 쓰기에 지인 키를 걸었다가 같은 날 PR #60 으로 되돌렸고 VM 갱신도 두 번 했다.
